# Raccourcis clavier

## Fenêtre principale

| Touche | Action |
| - | - |
| F1 | Aide |
| F5 | Recharger l'arbre |
| Ctrl+F | Rechercher (tous les champs, remplacer, identifiants) |
| Ctrl+G | Aller à (chercher une personne) |
| Ctrl+E | Fiche individuelle |
| Ctrl+N | Ajouter un parent |
| Ctrl+Enter | Personne sélectionnée comme personne centrale |
| Alt+Home | Personne de départ |
| Alt+Left / Alt+Right | Reculer / avancer dans l'historique |
| Ctrl+D | Ajouter aux favoris / retirer des favoris |
| Ctrl+B | Favoris |
| Ctrl+C, Ctrl+Shift+C | Copier le texte de la personne, avec l’identifiant (Ctrl+C seulement hors des champs de saisie ; aussi par clic droit sur une personne ; de même dans la fiche de personne, où le clic droit sur un événement copie aussi la ligne) |
| Ctrl+P | Imprimer la fiche individuelle |
| Ctrl+T | Tableau de descendance |
| Ctrl+Shift+T | Tableau d'ascendance |
| Ctrl+Shift+P | Vérification de cohérence |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Section Accueil / Arbre / Photos |
| Ctrl+4 | Table des personnes |
| Ctrl+5 | Sources |
| Ctrl+6 | Lieux |
| Ctrl+7 | Tâches |
| Ctrl+8 | Modifications récentes |
| Ctrl+9 | Archives |
| Ctrl+Q | Quitter |

## Navigateur

| Touche | Action |
| - | - |
| Flèche droite / Shift+Flèche droite | Vers le père / vers la mère |
| Flèche gauche | Vers le premier enfant de l'union affichée |
| Flèche haut / Flèche bas | Frère ou sœur précédent / suivant |
| Tab | Union suivante |
| Enter | Ouvrir la fiche individuelle |

## Vue famille

| Touche | Action |
| - | - |
| Flèche haut / Shift+Flèche haut | Vers le père / vers la mère |
| Flèche bas | Vers le premier enfant de l'onglet affiché |
| Flèche gauche / Flèche droite | Frère ou sœur précédent / suivant |
| Tab | Onglet suivant (union) |

## Fiche individuelle

| Touche | Action |
| - | - |
| Page Up / Page Down | Personne précédente / suivante de la liste |
| Ctrl+Home / Ctrl+End | Première / dernière personne |
| Double-clic sur une ligne | Modifier l'événement |
| Esc | Fermer |

## Aperçu des tableaux

| Saisie | Action |
| - | - |
| Molette de la souris | Zoomer autour du pointeur |
| Faire glisser | Déplacer la vue |
| Clic | Feuille entière / taille de lecture |
| Clic droit sur une case | Colorer ou masquer la branche |
| Esc | Fermer la fenêtre |

## Navigateur et arbre

| Saisie | Action |
| - | - |
| Clic | La personne devient la personne centrale |
| Double-clic | Fiche individuelle |
| Bouton droit de la souris | Comme personne centrale, modifier, ajouter aux favoris, ouvrir dans webtrees |
| Molette de la souris (arbre au centre) | Zoom |

**Esc** ferme toutes les fenêtres, y compris cette aide. Les raccourcis figurent aussi dans les menus à côté des entrées.
