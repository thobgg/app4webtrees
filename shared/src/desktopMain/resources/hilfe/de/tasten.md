# Tastenkürzel

## Hauptfenster

| Taste | Wirkung |
| - | - |
| F1 | Hilfe |
| F5 | Stammbaum neu laden |
| Strg+F | Suchen (alle Felder, Ersetzen, Kennzeichen) |
| Strg+G | Gehe zu (Person suchen) |
| Strg+E | Personenblatt |
| Strg+N | Verwandte hinzufügen |
| Strg+Eingabe | Gewählte Person als Proband |
| Alt+Pos1 | Startperson |
| Alt+Links / Alt+Rechts | Zurück / Vor im Verlauf |
| Strg+D | Merken / nicht mehr merken |
| Strg+B | Merkliste |
| Strg+C, Strg+Umschalt+C | Personentext kopieren, mit Kennung (Strg+C nur außerhalb von Eingabefeldern; auch per Rechtsklick auf eine Person; im Personenblatt ebenso, dort kopiert der Rechtsklick auf ein Ereignis auch die Zeile) |
| Strg+P | Personenblatt drucken |
| Strg+T | Stammtafel |
| Strg+Umschalt+T | Ahnentafel |
| Strg+Umschalt+P | Plausibilitätsprüfung |
| Strg+1 / Strg+2 / Strg+3 | Bereich Start / Baum / Fotos |
| Strg+4 | Personentabelle |
| Strg+5 | Quellen |
| Strg+6 | Orte |
| Strg+7 | Aufgaben |
| Strg+8 | Letzte Änderungen |
| Strg+9 | Archiv |
| Strg+Q | Beenden |

## Navigator

| Taste | Wirkung |
| - | - |
| Pfeil rechts / Umschalt+Pfeil rechts | Zum Vater / zur Mutter |
| Pfeil links | Zum ersten Kind der gezeigten Partnerschaft |
| Pfeil hoch / Pfeil runter | Voriges / nächstes Geschwister |
| Tab | Nächste Partnerschaft |
| Eingabe | Personenblatt öffnen |

## Familienansicht

| Taste | Wirkung |
| - | - |
| Pfeil hoch / Umschalt+Pfeil hoch | Zum Vater / zur Mutter |
| Pfeil runter | Zum ersten Kind des gezeigten Reiters |
| Pfeil links / Pfeil rechts | Voriges / nächstes Geschwister |
| Tab | Nächster Reiter (Partnerschaft) |

## Personenblatt

| Taste | Wirkung |
| - | - |
| Bild auf / Bild ab | Vorige / nächste Person der Liste |
| Strg+Pos1 / Strg+Ende | Erste / letzte Person |
| Doppelklick auf eine Zeile | Ereignis bearbeiten |
| Esc | Schließen |

## Tafel-Vorschau

| Eingabe | Wirkung |
| - | - |
| Mausrad | Zoom um die Stelle unter dem Zeiger |
| Ziehen | Verschieben |
| Klick | Ganzes Blatt / Lesegröße |
| Rechtsklick auf Kasten | Zweig färben oder ausblenden |
| Esc | Fenster schließen |

## Navigator und Baum

| Eingabe | Wirkung |
| - | - |
| Klick | Person wird Proband |
| Doppelklick | Personenblatt |
| Rechte Maustaste | Als Proband, Bearbeiten, Merken, in webtrees öffnen |
| Mausrad (Baum im Mittelpunkt) | Zoom |

**Esc** schließt jedes Fenster, auch diese Hilfe. Die Tastenkürzel stehen auch in den Menüs neben den Einträgen.
