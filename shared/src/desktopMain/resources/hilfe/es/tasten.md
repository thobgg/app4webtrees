# Atajos de teclado

## Ventana principal

| Tecla | Acción |
| - | - |
| F1 | Ayuda |
| F5 | Recargar el árbol |
| Ctrl+F | Buscar (todos los campos, reemplazar, identificadores) |
| Ctrl+G | Ir a (buscar persona) |
| Ctrl+E | Ficha personal |
| Ctrl+N | Añadir pariente |
| Ctrl+Enter | Persona seleccionada como persona central |
| Alt+Home | Persona de inicio |
| Alt+Left / Alt+Right | Atrás / adelante en el historial |
| Ctrl+D | Añadir marcador / quitar marcador |
| Ctrl+B | Marcadores |
| Ctrl+C, Ctrl+Shift+C | Copiar texto de la persona, con identificador (Ctrl+C solo fuera de los campos de entrada; también con clic derecho sobre una persona; igual en la hoja de persona, donde el clic derecho sobre un evento copia también la fila) |
| Ctrl+P | Imprimir ficha personal |
| Ctrl+T | Gráfico de descendientes |
| Ctrl+Shift+T | Gráfico de antepasados |
| Ctrl+Shift+P | Comprobación de plausibilidad |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Sección Inicio / Árbol / Fotos |
| Ctrl+4 | Tabla de personas |
| Ctrl+5 | Fuentes |
| Ctrl+6 | Lugares |
| Ctrl+7 | Tareas |
| Ctrl+8 | Cambios recientes |
| Ctrl+9 | Archivo |
| Ctrl+Q | Salir |

## Navegador

| Tecla | Acción |
| - | - |
| Flecha derecha / Shift+flecha derecha | Al padre / a la madre |
| Flecha izquierda | Al primer hijo de la pareja mostrada |
| Flecha arriba / flecha abajo | Hermano anterior / siguiente |
| Tab | Pareja siguiente |
| Enter | Abrir la ficha personal |

## Vista de familia

| Tecla | Acción |
| - | - |
| Flecha arriba / Shift+flecha arriba | Al padre / a la madre |
| Flecha abajo | Al primer hijo de la pestaña mostrada |
| Flecha izquierda / flecha derecha | Hermano anterior / siguiente |
| Tab | Pestaña siguiente (pareja) |

## Ficha personal

| Tecla | Acción |
| - | - |
| Page Up / Page Down | Persona anterior / siguiente de la lista |
| Ctrl+Home / Ctrl+End | Primera / última persona |
| Doble clic en una fila | Editar evento |
| Esc | Cerrar |

## Vista previa del gráfico

| Entrada | Acción |
| - | - |
| Rueda del ratón | Zoom alrededor del puntero |
| Arrastrar | Desplazar |
| Clic | Hoja completa / tamaño de lectura |
| Clic derecho en una casilla | Colorear u ocultar la rama |
| Esc | Cerrar la ventana |

## Navegador y árbol

| Entrada | Acción |
| - | - |
| Clic | La persona pasa a ser la persona central |
| Doble clic | Ficha personal |
| Botón derecho del ratón | Como persona central, editar, añadir marcador, abrir en webtrees |
| Rueda del ratón (árbol en el centro) | Zoom |

**Esc** cierra cualquier ventana, también esta ayuda. Los atajos también aparecen en los menús junto a las entradas.
