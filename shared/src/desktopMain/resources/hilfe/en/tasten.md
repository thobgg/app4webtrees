# Keyboard shortcuts

## Main window

| Key | Action |
| - | - |
| F1 | Help |
| F5 | Reload tree |
| Ctrl+F | Search (all fields, replace, identifiers) |
| Ctrl+G | Go to (find person) |
| Ctrl+E | Person sheet |
| Ctrl+N | Add relative |
| Ctrl+Enter | Selected person as central person |
| Alt+Home | Start person |
| Alt+Left / Alt+Right | Back / forward in history |
| Ctrl+D | Bookmark / remove bookmark |
| Ctrl+B | Bookmarks |
| Ctrl+C, Ctrl+Shift+C | Copy person text, with ID (Ctrl+C only outside input fields; also by right-clicking a person; the same in the person sheet, where right-clicking an event also copies the row) |
| Ctrl+P | Print person sheet |
| Ctrl+T | Descendant chart |
| Ctrl+Shift+T | Ancestor chart |
| Ctrl+Shift+P | Plausibility check |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Section Home / Tree / Photos |
| Ctrl+4 | Person table |
| Ctrl+5 | Sources |
| Ctrl+6 | Places |
| Ctrl+7 | Tasks |
| Ctrl+8 | Recent changes |
| Ctrl+9 | Archive |
| Ctrl+Q | Quit |

## Navigator

| Key | Action |
| - | - |
| Right arrow / Shift+Right arrow | To the father / to the mother |
| Left arrow | To the first child of the partnership shown |
| Up arrow / Down arrow | Previous / next sibling |
| Tab | Next partnership |
| Enter | Open the person sheet |

## Family view

| Key | Action |
| - | - |
| Up arrow / Shift+Up arrow | To the father / to the mother |
| Down arrow | To the first child of the tab shown |
| Left arrow / Right arrow | Previous / next sibling |
| Tab | Next tab (partnership) |

## Person sheet

| Key | Action |
| - | - |
| Page Up / Page Down | Previous / next person in the list |
| Ctrl+Home / Ctrl+End | First / last person |
| Double-click on a row | Edit event |
| Esc | Close |

## Chart preview

| Input | Action |
| - | - |
| Mouse wheel | Zoom around the pointer |
| Drag | Pan |
| Click | Whole sheet / reading size |
| Right-click on a box | Colour or hide the branch |
| Esc | Close window |

## Navigator and tree

| Input | Action |
| - | - |
| Click | Person becomes central person |
| Double-click | Person sheet |
| Right mouse button | As central person, edit, bookmark, open in webtrees |
| Mouse wheel (tree in the centre) | Zoom |

**Esc** closes every window, including this help. The shortcuts are also shown in the menus next to the entries.
