# Sneltoetsen

## Hoofdvenster

| Toets | Functie |
| - | - |
| F1 | Help |
| F5 | Stamboom opnieuw laden |
| Ctrl+F | Zoeken (alle velden, vervangen, kenmerken) |
| Ctrl+G | Ga naar (persoon zoeken) |
| Ctrl+E | Persoonsblad |
| Ctrl+N | Verwant toevoegen |
| Ctrl+Enter | Geselecteerde persoon als proband |
| Alt+Home | Startpersoon |
| Alt+Links / Alt+Rechts | Terug / vooruit in de geschiedenis |
| Ctrl+D | Bladwijzer / bladwijzer verwijderen |
| Ctrl+B | Bladwijzers |
| Ctrl+C, Ctrl+Shift+C | Persoonstekst kopiëren, met ID (Ctrl+C alleen buiten invoervelden; ook via rechtsklik op een persoon; in het persoonsblad eveneens, daar kopieert rechtsklik op een gebeurtenis ook de regel) |
| Ctrl+P | Persoonsblad afdrukken |
| Ctrl+T | Parenteel |
| Ctrl+Shift+T | Kwartierstaat |
| Ctrl+Shift+P | Plausibiliteitscontrole |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Onderdeel Start / Boom / Foto's |
| Ctrl+4 | Personentabel |
| Ctrl+5 | Bronnen |
| Ctrl+6 | Plaatsen |
| Ctrl+7 | Taken |
| Ctrl+8 | Recente wijzigingen |
| Ctrl+9 | Archief |
| Ctrl+Q | Afsluiten |

## Navigator

| Toets | Functie |
| - | - |
| Pijl rechts / Shift+Pijl rechts | Naar de vader / naar de moeder |
| Pijl links | Naar het eerste kind van de getoonde relatie |
| Pijl omhoog / Pijl omlaag | Vorige / volgende broer of zus |
| Tab | Volgende relatie |
| Enter | Persoonsblad openen |

## Gezinsweergave

| Toets | Functie |
| - | - |
| Pijl omhoog / Shift+Pijl omhoog | Naar de vader / naar de moeder |
| Pijl omlaag | Naar het eerste kind van het getoonde tabblad |
| Pijl links / Pijl rechts | Vorige / volgende broer of zus |
| Tab | Volgend tabblad (relatie) |

## Persoonsblad

| Toets | Functie |
| - | - |
| Page Up / Page Down | Vorige / volgende persoon in de lijst |
| Ctrl+Home / Ctrl+End | Eerste / laatste persoon |
| Dubbelklik op een rij | Gebeurtenis bewerken |
| Esc | Sluiten |

## Voorbeeldweergave van schema's

| Invoer | Functie |
| - | - |
| Muiswiel | Zoomen rond de muisaanwijzer |
| Slepen | Verschuiven |
| Klik | Heel blad / leesgrootte |
| Rechtsklik op een vak | Tak kleuren of verbergen |
| Esc | Venster sluiten |

## Navigator en boom

| Invoer | Functie |
| - | - |
| Klik | Persoon wordt proband |
| Dubbelklik | Persoonsblad |
| Rechtermuisknop | Als proband, bewerken, bladwijzer, openen in webtrees |
| Muiswiel (Boom centraal) | Zoomen |

**Esc** sluit elk venster, ook deze help. De sneltoetsen staan ook in de menu's naast de menu-items.
